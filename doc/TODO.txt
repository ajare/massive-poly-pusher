New mesh system
---------------

Goal:
- To be able to specify a Mesh entirely based on:
  - Mesh specification
  - Functions to set components, eg
      auto vi = addVertex();
	  setVertexPosition(vi, 0, 0, 0);
	  
	  and so on

- The idea is to simplify Mesh creation and wrap it all.
- Shaders are generated based on the Mesh specification.
  - Either write them manually, or use defaults
  - Just specify Position2/3/4 etc as the variable names.  The type is deduced & generated from the Mesh specification
- Might be able to use templating, eg like in Willpower to have a specialised class
  with correct types.  Would have to use GL datatype values though, can't use C types
  for template arguments, in order to be able to use half floats, dvec4 etc.  So template
  params would be a set of integers, not types: check this is possible.
- See about passing in data other than pos/normal/tex/colour, and how that would work
